# Test vector provenance

`megolm-v1.json` in this directory is **not** an official upstream vodozemac
known-answer test (KAT) file. It was generated by the maintainers of
`@kinsh/vodozemac-wasm` using their own `scripts/generate-test-vectors.mjs`
(committed to
https://github.com/Meneleus/vodozemac-bindings/blob/main/test-vectors/megolm-v1.json),
which builds a fresh Megolm outbound session with the pkg-node WASM build and
records the session key, an export-at-index-2 key, an inbound pickle, and four
encrypted messages.

It is used here as a **cross-build consistency check** (does the pkg-web/pkg-node
artifact still decrypt data produced by the same library version?), not as an
independent cryptographic validation.

**Why no official KATs:** upstream vodozemac (matrix-org/vodozemac) does not
publish standalone JSON test-vector files; its known-answer tests are embedded
in Rust `#[cfg(test)]` modules and require a Rust toolchain to run. No Rust
toolchain is available in this environment, so those tests were not executed.
See BLOCKERS.md.

Provenance was verified by reading the generator script; the file is vendored
verbatim so the suite runs offline and cannot drift if upstream changes.
